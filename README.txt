CHAOS RUSH — PROTOTIPO 0.1

Contenido:
- index.html: estructura del juego
- style.css: diseño adaptable a celular y computadora
- game.js: carrera arcade local, joystick táctil, teclado, nitro, vueltas y cronómetro

PRUEBA:
1. Descomprime el ZIP.
2. Abre index.html en un navegador moderno.
3. Pulsa INICIAR CARRERA.
4. Usa el joystick en pantalla o las flechas/A-D del teclado.
5. Pulsa NITRO para consumir una carga.

PUBLICACIÓN GRATUITA:
1. Crea una cuenta en Cloudflare.
2. Entra a Workers & Pages > Create > Pages > Upload assets.
3. Sube los tres archivos (index.html, style.css, game.js) o la carpeta.
4. Cloudflare te dará una URL pages.dev.

IMPORTANTE:
Esta versión es un prototipo individual. Todavía NO conecta varios celulares.
La siguiente etapa será crear salas y sincronización multijugador con Firebase Realtime Database.
